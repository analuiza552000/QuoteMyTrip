# QuoteMyTrip
Tour Operator Quotation Builder and Pricing Engine


## **WHY?**

This project was inspired by real operational needs in a tour operator business. It aims to facilitate the day to day activities of tour operators. There is a lot of reuse and repetition to the quotation building process, and instead of redoing over and over the same activity, this is a tool to optimize time in each task.

## **SCOPE**

- Local database with default prices per destination
- Local database with tour and service descriptions  
- Markup calculator
- User input for category-based pricing  
- Interactive quote builder with multi-item pricing

### *Future Add-ons*
- Itinerary builder  
- PDF quotation exporter

## Tech Environment

- Python
- SQLite
- Streamlit
